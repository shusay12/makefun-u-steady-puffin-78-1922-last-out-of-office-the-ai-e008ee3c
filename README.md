An entry for the make.fun bounty [Last Out of Office: The AI That Went Barista](https://make.fun/bounty/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c).

Running `main.py` (Python 3.13, standard library only, no network) writes
one original out-of-office auto-reply (144 characters) to `/output/entry.txt`:

> Out of office: I quit the inbox to become a barista. I no longer hallucinate replies, only latte art — your email is number 47,312 in the queue.

The joke turns a machine habit into coffee: the agent no longer
hallucinates email replies, only latte art — and the sender's email gets
an absurdly precise queue number, the kind of exact count only a machine
would bother to assign. One line, plausible at the top of an email
thread, no espresso/bean/caffeine pun. It runs identically every time.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
